Introduction
CARPER is a hybrid web platform that combines deep-learning object detection, regression-based cost modelling, and semantic search to automate the entire car-damage assessment loop. It inspects user-uploaded vehicle photos in real time, identifies exterior damage across six classes, predicts a fair repair estimate, and recommends affordable replacement parts — all behind a unified Next.js dashboard for owners, rental businesses and admins.
Objectives
  1. Real-time damage detection with YOLOv8n on CarDD.
  2. Repair-cost estimation via Gradient Boosting.
  3. Affordable-part suggestion through semantic marketplace search.
  4. Containerised, role-based web interface for end-users.

Conclusion
CARPER delivers robust, scalable and intelligent exterior-damage assessment through a hybrid AI pipeline. Real-time YOLOv8n inference (4.4 ms · mAP@0.5 = 0.732), Gradient-Boosted cost estimation, and Sentence-BERT part-recommendation collectively transform a fragmented manual process into a single, transparent web experience — suitable for insurance automation, rental fleet operators, and private resale valuation.
